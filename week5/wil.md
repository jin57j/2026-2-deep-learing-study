이번 주에는 자연어 처리의 발전 과정을 따라가며 RNN, LSTM, GRU, Seq2Seq, Attention의 구조와 등장 배경을 학습했다.
먼저 자연어는 단어 자체의 의미뿐 아니라 순서와 문맥에 따라 의미가 달라지는 순차 데이터라는 점을 살펴보았다. 이를 처리하기 위해 RNN은 이전 정보를 Hidden State로 전달하지만, 시퀀스가 길어질수록 기울기 소실로 인해 오래된 정보를 학습하기 어렵다는 한계가 있었다.

LSTM과 GRU는 이러한 문제를 완화하기 위해 등장했다. 특히 LSTM에서 Cell State를 별도로 사용하는 이유가 궁금했는데 기존 기억을 유지하는 경로와 현재 사용할 정보를 표현하는 경로를 분리함으로써 장기적인 정보 전달을 돕는다는 점을 이해했다. GRU는 별도의 Cell State 없이 게이트를 통해 기존 정보와 새로운 정보의 반영 비율을 조절한다는 차이가 있었다.

실습에서는 RNN, LSTM, GRU를 이용해 마지막 색상 지시를 기억하는 문제를 해결했다. 처음에는 입력 데이터의 Shape과 토큰의 구성이 직관적으로 이해되지 않았지만 이미지 분류에서 사진 한 장이 데이터 하나였다면 이번에는 96개의 토큰으로 구성된 시퀀스 하나가 데이터 하나라는 점을 이해했다. 또한 방해 토큰을 무작위로 배치하여 모델이 단순한 등장 빈도가 아닌 순서와 기억에 의존하도록 구성했다는 점도 알게 되었다.

실험 결과는 예상과 조금 달랐다. LSTM과 GRU가 장기 의존성 학습에 유리할 것이라 생각했지만 세 모델 모두 Gap 72까지 정확도 100%를 달성했다. 오히려 RNN이 가장 적은 파라미터와 짧은 학습 시간으로 동일한 정확도를 얻었다. 이를 통해 구조가 복잡하다고 반드시 더 좋은 결과를 얻는 것은 아니며, 문제의 특성에 따라 단순한 모델도 충분히 효과적일 수 있음을 확인했다.

이번 학습에서 가장 크게 이해가 달라진 부분은 Attention이었다. 이전에는 Attention을 입력에서 중요한 부분에 집중하는 방법이라는 추상적인 수준으로 이해하고 있었다. 하지만 Seq2Seq를 학습하면서 Attention이 왜 필요했는지 알 수 있었다.
기존 Seq2Seq는 Encoder가 입력 문장을 읽고 마지막 상태를 고정된 크기의 Context Vector로 전달한다. 문장이 길어질수록 많은 정보를 하나의 벡터에 압축해야 하므로 정보 병목이 발생할 수 있다. Attention은 이를 완화하기 위해 Decoder가 출력을 생성할 때마다 Encoder의 여러 은닉 상태를 다시 참조하도록 한다.

그 과정에서 Encoder와 Decoder의 상태를 이용해 관련성 점수를 계산하고, Softmax를 통해 참조 가중치를 구한 뒤, 각 은닉 상태의 가중합으로 현재 필요한 Context Vector를 생성한다. 즉 모든 정보를 하나의 표현에 담는 대신 필요한 시점에 필요한 정보를 선택적으로 가져오는 방식이라는 점에서 그 원리를 이해할 수 있었다.
