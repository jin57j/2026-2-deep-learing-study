## 비교 조건과 해석

길이 96의 입력에서 마지막 색 지시를 기억하는 합성 문제입니다.
각 배경에서 토큰 빈도가 같은 네 예시를 만들고, 마지막 지시의 색을 정답으로 사용합니다.
배경 그룹은 train/validation/test 사이에서 겹치지 않습니다.
첫 색과 정답의 조합도 균등하게 구성합니다.
색 지시 사이의 배치도 함께 정해지는 데이터이므로, gap별 차이가 특정 원인 하나만을 입증하지는 않습니다.

세 모델은 같은 embedding·hidden 크기와 데이터·학습 순서·optimizer·batch·epoch를 사용합니다.
같은 hidden 크기라도 파라미터 수는 다릅니다.
각 모델의 optimizer는 새로 만들며, 기본 실행은 seed 42 한 번입니다.
Test는 조건을 정한 뒤 최종 비교에 사용합니다.

학습 시간은 CPU에서 fit 전체(첫 tracing·학습·validation 포함)를 측정합니다.
다른 장비의 시간과 단순 비교하거나 파라미터 수만으로 속도를 판단하지 않습니다.
학습 곡선, 거리별 정확도, 파라미터 수, 동일 입력의 확률을 함께 관찰해주세요.
단순한 문제에서는 세 모델의 최종 정확도가 모두 같을 수 있습니다.
이 결과를 자연어 전반의 성능 순위나 gradient 소실의 직접 측정으로 해석하지 않습니다.

- [RNN 계산 흐름](imgs/rnn_memory.gif): 나는 → 사과를 → 좋아한다를 읽으며 고정 가중치로 상태를 계산합니다.
- [Seq2seq](imgs/seq2seq.gif): I like apples → 나는 사과를 좋아한다를 예로 마지막 encoder 상태를 고정된 context로 전달합니다.
- [Attention](imgs/attention.gif): 같은 예시에서 출력마다 encoder 표현을 참조하는 비율과 context가 달라집니다.

세 GIF는 자동 반복됩니다. RNN은 설명용 수치의 실제 순전파 계산이고,
번역문과 decoder 상태는 구조를 보여주기 위해 준비한 예시입니다.
Attention 참조 비율은 같은 점수 함수를 사용해 계산하며, 소수 셋째 자리로 표시해 합에 반올림 차이가 있을 수 있습니다.
Seq2seq와 attention의 상태·context·참조 가중치는 소수 셋째 자리로 통일해 표시합니다.
