이번 주차에는 ResNet의 구조와 Transfer Learning을 학습하고, 사전학습된 모델을 새로운 문제에 활용하는 실습을 진행했다.
먼저 Basic Residual Block과 Bottleneck Block을 직접 구현하고 파라미터 수와 실행 시간을 비교했다. Bottleneck은 중간 채널을 축소하여 파라미터와 연산량을 크게 줄였지만 실제 실행 시간은 같은 비율로 감소하지 않았다. 이를 통해 모델의 연산 효율이 단순히 파라미터 수만으로 결정되는 것은 아니라는 점을 확인했다.
이후 기존 ResNet을 활용하여 흑백 이미지에서 고양이와 강아지를 구분하는 새로운 Task를 구현했다. 기존 모델은 RGB 입력을 사용하므로, 흑백 이미지를 3채널로 변환하는 Input Adapter를 추가했다. ResNet의 가중치는 고정한 채 Adapter와 새로운 분류 Head만 학습시켰으며, Test 정확도 97.78%를 달성했다.
특히 이번 실습에서 인상 깊었던 부분은 기존 모델을 새로운 문제에 적용하기 위해 반드시 내부 가중치를 수정할 필요는 없다는 점이었다. 기존 모델의 입력과 출력에 새로운 구조를 추가하는 것만으로도 학습된 특징을 효과적으로 재활용할 수 있었다.
마지막으로 Checkpoint를 저장하고 커널을 재시작한 뒤 모델을 복원하는 과정까지 진행했다. 이를 통해 모델의 학습, 저장, 복원, 평가가 각각 어떤 역할을 하는지 이해할 수 있었다.
결과적으로 이번 실습은 신경망의 구조를 개선하는 방법부터 기존 모델의 지식을 새로운 문제에 활용하는 과정까지 경험해 볼 수 있는 시간이었다.
이번 주차에서는 이전 과제들과 달리 코드를 읽어도 전체적인 흐름이 쉽게 그려지지 않았다. 이전에는 Convolution이나 Pooling처럼 개별 연산을 중심으로 학습했기 때문에 코드와 실제 계산 과정을 연결하기 쉬웠지만 이번에는 adapter, Backbone, Encoder, Head처럼 여러 연산을 하나의 구조로 묶어 다루면서 생소하게 느껴졌다.
처음에는 코드에 익숙하지 않아 AI에 지나치게 의존하고 있다고 생각했지만 돌이켜보니 내용 자체가 어려워졌다기보다 다루는 추상화의 단위가 달라진 것이 더 큰 이유였던 것 같다. 앞으로는 새로운 구조를 접했을 때 그 내부에 어떤 연산들이 포함되어 있는지 먼저 살펴보고 전체 모델에서 어떤 역할을 하는지 이해하는 방식으로 학습해야겠다고 느꼈다.
